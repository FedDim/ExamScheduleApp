## Описание

«Генератор расписания экзаменов» — это приложение для Windows, предназначенное для автоматизации процесса составления расписания экзаменационной сессии в учебном заведении. Программа позволяет управляющему учебной частью быстро формировать записи о запланированных экзаменах и консультациях, выбирая преподавателя, дисциплину, группу, дату, время и аудиторию, а затем экспортировать готовое расписание в документ Microsoft Word.

Приложение работает со справочниками преподавателей, дисциплин и учебных групп, которые хранятся в текстовых файлах. Это обеспечивает простоту настройки и возможность редактирования данных вручную в любом текстовом редакторе.

**Ветвь [`spletalo-brubch`](https://github.com/FedDim/ExamScheduleApp/tree/spletalo-brubch) содержит версию 2.0** приложения с масштабной переработкой архитектуры, переходом на базу данных SQLite, полноценным CRUD-интерфейсом и улучшенным экспортом в Word. Подробнее о версии 2.0 — в соответствующем разделе ниже.

## Возможности

| Функция | Описание |
|---|---|
| **Справочники** | Загрузка преподавателей, дисциплин и групп из текстовых файлов в выпадающие списки |
| **Добавление данных** | Возможность добавления новых преподавателей, дисциплин и групп через диалоговое окно |
| **Формирование расписания** | Заполнение полей: дата, преподаватель, дисциплина, группа, время, аудитория, тип (экзамен / консультация) |
| **Таблица экзаменов** | DataGrid с отображением всех добавленных записей по 8 столбцам |
| **Экспорт в Word** | Генерация документа Word с таблицей расписания через COM-автоматизацию Microsoft Office |
| **Валидация групп** | Проверка формата названия группы по маске `XX-NN` (две кириллические буквы + дефис + две цифры) |

## Установка и запуск

### Из исходного кода

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/FedDim/ExamScheduleApp.git
   ```

2. **Откройте решение в Visual Studio:**
   ```
   ExamScheduleApp.sln
   ```

3. **Восстановите пакеты NuGet:**
   - В обозревателе решений щёлкните правой кнопкой по проекту
   - Выберите *«Управление пакетами NuGet»*
   - Убедитесь, что установлены необходимые пакеты

4. **Соберите и запустите:**
   - Нажмите `F5` или кнопку *«Запуск»*
   - Либо `Ctrl + Shift + B` для сборки, затем запустите `.exe` из папки `bin/Debug` или `bin/Release`

> **Важно:** перед первым запуском убедитесь, что пути к файлам данных в `MainWindow.xaml.cs` указывают на корректную директорию на вашем компьютере. По умолчанию пути ведут к папке проекта разработчика.

### Из готового исполняемого файла

Скомпилированный `.exe` находится в директории `bin/Debug` или `bin/Release` после сборки. Для работы необходима установленная версия .NET Framework 4.7.2 и Microsoft Word.

## Использование

### Интерфейс

Главное окно приложения разделено на две панели:

- **Левая панель — «Управление данными»:** три кнопки для добавления преподавателей, дисциплин и групп. При нажатии открывается диалоговое окно с полем ввода. Для групп действует проверка формата: две заглавные кириллические буквы, дефис и две цифры (например, `ДВ-45`).

- **Правая панель — «Создание расписания»:** форма с выпадающими списками и полями:
  - *Дата экзамена* — выбор даты через DatePicker
  - *Преподаватель* и *Преподаватель 2* — выбор из справочника
  - *Дисциплина* — выбор из справочника
  - *Группа* — выбор из справочника
  - *Время* — текстовое поле (по умолчанию `10:00`)
  - *Аудитория* — текстовое поле
  - *Тип* — выбор: «Экзамен» или «Консультация»

### Добавление записи

1. Заполните все поля в правой панели
2. Нажмите кнопку *«Добавить экзамен/консультацию»*
3. Запись появится в таблице в нижней части окна

### Экспорт в Word

1. После заполнения таблицы нажмите кнопку *«Создать файл расписания»*
2. Приложение автоматически запустит Microsoft Word
3. Документ будет сохранён на рабочий стол с названием «Экзамены»

> Требуется установленный Microsoft Word. Документ создаётся в формате `.docx` с таблицей, содержащей все записи из DataGrid.

## Формат данных

Приложение хранит справочные данные в трёх текстовых файлах в кодировке UTF-8. Каждый файл представляет собой список строк, где каждая строка — отдельная запись.

### Преподаватели (`Data/teachers.txt`)

Фамилии преподавателей в верхнем регистре, по одной на строку:

```
АГАФОНОВ
БАЛАШКО
БЕРЕЗИН
ВДОВИЧЕВА
...
```

### Дисциплины (`Data/disciplines.txt`)

Названия дисциплин, по одному на строку (допускаются сокращения):

```
Информатика
Математика
Физика
Электроника
...
```

### Группы (`Data/groups.txt`)

Код группы в формате `XX-NN`:

```
ДА-11
ДА-12
ДТ-21
КТ-31
...
```

При добавлении новых записей через приложение выполняется автоматическая сортировка по алфавиту и удаление дубликатов.

## Версия 2.0 (ветка `spletalo-brubch`)

Ветка [`spletalo-brubch`](https://github.com/FedDim/ExamScheduleApp/tree/spletalo-brubch) содержит полностью переработанную версию приложения с 36 коммитами изменений. Это развитие проекта, в котором устранены ключевые ограничения первой версии и добавлен ряд новых возможностей.

### Что изменилось

| Область | Версия 1.0 (master) | Версия 2.0 (spletalo-brubch) |
|---|---|---|
| **Хранение данных** | Текстовые файлы (`.txt`) | SQLite база данных (`ExamScheduleDB.db`) |
| **Модели** | `Subject`, `Teacher` | `Discipline`, `Group`, расширенный `Teacher` |
| **Добавление данных** | Универсальное окно `AddWindow` в корне проекта | Перенесённое в `View/`, переработанное окно |
| **Редактирование** | Не поддерживается | Отдельное окно `EditWindow` |
| **Удаление** | Не поддерживается | Удаление записей из таблицы |
| **Экспорт в Word** | Встроенный в `MainWindow.xaml.cs` | Выделенный класс `WordHelper` (+921 строка) |
| **Работа с БД** | Чтение/запись текстовых файлов | `SimpleDatabaseHelper` (+794 строки) — полноценный CRUD |
| **Таблица расписания** | DataGrid в главном окне | Отдельное окно `ScheduleTableWindow` |
| **Новое поле** | — | «Отделение» — добавлено в модель и БД |
| **Отладка** | — | Окно разработчика `DevWindow` |
| **Иконки** | Стандартные WPF | Кастомные иконки приложения |
| **Формат групп** | Regex-проверка `^[А-ЯЁ]{2}-\d{2}$` | Валидация через БД |

### Ключевые улучшения

- **Полноценная база данных** — переход от текстовых файлов к SQLite обеспечил целостность данных, поддержку связей между таблицами и возможность сложных запросов. Слой работы с БД вынесен в отдельный класс `SimpleDatabaseHelper`.

- **CRUD-интерфейс** — появилась возможность не только добавлять, но и редактировать и удалять записи. Редактирование доступно через отдельное окно `EditWindow`, а удаление — через контекстное меню в таблице.

- **Выделенный Word-экспорт** — логика генерации документов Word вынесена в `WordHelper.cs`, что сделало код более поддерживаемым. Документы теперь содержат шапку, подпись заведующего учебной частью и инициалы преподавателей.

- **Отдельное окно таблицы** — `ScheduleTableWindow` позволяет работать с полной таблицей расписания независимо от формы добавления записей, включая сортировку и удаление.

- **Совместная разработка** — в проект также внёс вклад [Kirill Stepnov](https://github.com/StepnovKY) (иконки приложения и часть исправлений).
